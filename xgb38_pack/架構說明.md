# XGB38 選股與預約交易架構

## 現行原則

- 選股只使用 `adjpx`：yfinance `auto_adjust=True` 的還原 OHLCV。
- 只保留 `models/adjpx/`，沒有價格來源切換。
- `stock_api` 的未還原價只用於實際委託價、張數、ATR 與庫存估值，不會送入 adjpx 模型。
- CLI 只產生預覽；`--execute` 會直接報錯。
- 只有 GUI 勾選委託並經使用者確認後，才會呼叫 `Buy_Stock` / `Sell_Stock`。
- 賣出清倉的張數來自送單前重新查詢的 API 實際庫存；預約紀錄只用於防重送與稽核。

## 資料流

```text
yfinance 還原 OHLCV + FinMind 籌碼
                 ↓
features_build.py：50 檔整池計算，固定 38 欄
                 ↓
model_adapter.py：當季 3 顆 XGBRegressor 取平均
                 ↓
每檔 score 與當日全池 rank
                 ↓
strategy.py：排名、流動性、持股、預算、停損停利
                 ↓
BUY / SELL / HOLD 計畫
                 ↓
trading_backend.py：重查實際庫存 + stock_api 未還原價
                 ↓
GUI 顯示；使用者勾選、確認後才送出
```

## 各層責任

| 層 | 檔案 | 責任 |
|---|---|---|
| 股票池 | `universe.py`, `universe_tw50.csv` | 產生 50 檔 yfinance ticker |
| 模型價格 | `price_data.py` | 下載、正規化、快取 adjpx |
| 實際委託價 | `price_data.fetch_execution_price()` | 透過公開 `stock_api` 取未還原 OHLCV |
| 籌碼 | `chip_data.py` | FinMind 三個 dataset 的增量快取 |
| 特徵 | `features_build.py`, `features/` | 整池產生與驗證 38 欄特徵 |
| 模型 | `model_adapter.py`, `models/adjpx/` | 驗證季度與特徵順序，輸出排名 |
| 策略 | `strategy.py` | 將排名轉成 BUY / SELL / HOLD |
| 預覽 | `run_strategy.py`, `run_model_strategy.py` | 產生 JSON 報告，永不送單 |
| 交易整合 | `trading_backend.py`, `broker_worker.py` | 查實際持股、重算委託、防重複送出 |
| 操作界面 | `trading_gui.py` | 顯示庫存、計畫與紀錄，確認後送出 |
| 每晚計畫 | `nightly_plan.py` | 只調用 `prepare()`，不調用 `submit()` |

## 模型輸出的意義

模型目標是 T+1 開盤至收盤報酬在當日股票池的百分位。`score` 是相對分數，不是價格、機率或可使用絕對門檻的預測報酬。策略依 `rank` 選股。

38 欄特徵的順序固定為 `feature_shortlist_v2.csv`。其中含當日橫斷面特徵，因此必須同時處理全部 50 檔，不能單檔獨立推論。

## 策略規則

- 最多持有 3 檔。
- 持股掉出前 5 名即產生賣出計畫。
- 買進從前 15 名中依序選擇。
- 5 日均量至少 2,000 張。
- 實單只使用整張，1 張 = 1,000 股。
- 買進預算不預支尚未成交的賣出款。
- 清倉賣出數量必須完全等於送單當下 API 回報的庫存張數。

## 執行方式

CLI 預覽：

```powershell
python -B -X utf8 run_model_strategy.py --date 2026-09-24 --cash 3000000
```

離線預覽：

```powershell
python -B -X utf8 run_model_strategy.py --offline --date 2026-09-24 --cash 3000000
```

GUI：

```powershell
.\launch_trading_gui.ps1
```

`--execute` 不是可用的 CLI 功能。每晚排程也只產生計畫。

## 限制與未解風險

1. 只有 2026Q1～Q3 的三組模型；2026-10-01 起需要 Q4 模型才能執行。
2. `universe_tw50.csv` 是固定成分股清單，不會自動反映歷史或未來調整。
3. `chip_shift=0`；外資持股比的歷史發布時點尚未完成 point-in-time 驗證。
4. API 「預約成功」不等於成交；現有 API 沒有委託查詢、成交明細或取消函數。
5. 本地「已刪單」只是紀錄，不會呼叫交易 API 取消委託。
6. 回測允許零股，GUI 只允許整張，高價股可能因預算不足而被跳過。
7. 停損停利沒有盤中回呼，實際出場時間可與回測不同。

## 歷史績效記錄

adjpx 版原始記錄的 2026-01-02～2026-09-24 回測為：無成本 +146.99%，納入手續費與證交稅後 +88.65%。這是歷史回測紀錄，不是實單成績或未來保證。
